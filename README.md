# Trade Reconciliation & Break Investigation Using Excel

## Project Overview

This is a self-developed learning project demonstrating how internal trade records can be compared with counterparty records to identify discrepancies.

## Objectives

* Identify quantity mismatches.
* Detect price discrepancies.
* Flag settlement-date mismatches.
* Summarise exceptions for investigation.
* Present reconciliation results in a dashboard.

## Workbook Structure

* **Trade_Data:** Sample trade records and reconciliation checks.
* **Exception_Report:** Identified breaks and suggested actions.
* **Dashboard:** Summary of trade counts and break categories.
* **AI_Break_Investigation:** Rule-based examples of possible break causes and investigation steps.

## Tools and Concepts

Microsoft Excel, IF, AND, COUNTIF, COUNTA, INDEX, MATCH, IFERROR, reconciliation checks, exception reporting.

## Sample Results

The sample workbook contains four trades: one matched trade and three trades with discrepancies.

## Disclaimer

This is an educational project using illustrative data. It does not contain actual bank or client records. Investigation suggestions are examples for learning purposes and are not generated by an integrated AI model.

## Learning Outcomes

Understanding basic trade matching, exception identification, reconciliation reporting, and the importance of accurate trade data.
